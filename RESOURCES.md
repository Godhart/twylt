# TWYLT related resources

## Lab + ToolHub

TWYLT is inspired by this tools and designed for this tools in first place:

- **Lab** https://github.com/Talos-popcorn/lab
- **Toolhub** https://github.com/Talos-popcorn/toolhub

## TWYLT itself

- TWYLT **specification** and **Python** implementation https://github.com/Godhart/twylt
- TWYLT **Typescript** implementation https://github.com/Godhart/twylt-typescript

## TWYLTed Tools

### General usage

- Toolpak for **essential** things like sleep, echo checking, ping, wget, curl etc. https://github.com/Godhart/twylt-pack-essential
- Toolpak for general **filesystem** opreations https://github.com/Godhart/twylt-pack-filesystem
- Toolpak for **git** operaions https://github.com/Godhart/twylt-pack-git
- Toolpak for **running apps** under docker/podman https://github.com/Godhart/twylt-pack-docker

### Documentation

- **Documentation handling** https://github.com/Godhart/docsanity and https://github.com/Godhart/docsanity-dependency-manifest

### Hardware dev

- **HDL** code analysis https://github.com/Godhart/hdl-order

## Toolhub supplementary

- Build **toolkit pack** for Toolhub out of bunch TWYLTed tools https://github.com/Godhart/toolpack-builder
- **MCP** bridge for Toolhub https://github.com/Godhart/toolhub-mcp-bridge
- **Docker/Podman** images for running tools in controlled environment https://github.com/Godhart/toolhub-images
- **Gateway** for running on hosting, exposing MCP interface with OAuth https://github.com/Godhart/toolhub-gateway.git
